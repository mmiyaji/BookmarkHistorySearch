# Chrome Web Store Copy

## English

### Title
Tadorun - Bookmark, History & Tab Search

### Short Description
Search bookmarks, browsing history, and recently closed tabs from one fast popup.

### Full Description
Tadorun helps you find pages you have seen before without leaving your current tab.

Use one popup to search across bookmarks, Chrome history, and recently closed tabs. You can narrow results with `site:`, `title:`, and `url:` operators, save frequent searches, and move through results with the keyboard.

Key features:
- Unified search for bookmarks, history, and recently closed tabs
- Structured search operators: `site:`, `title:`, `url:`
- Saved searches and recent searches
- Domain and folder filters
- Copy URL, open in a new tab, and inline bookmark edit/delete
- Multi-language UI

Permissions note:
- `bookmarks`: search and edit bookmarks
- `history`: search browsing history
- `sessions`: show recently closed tabs
- `tabs`: detect already open pages
- `storage`: save settings and searches

### Suggested Keywords
bookmark search, history search, recently closed tabs, chrome productivity, tab finder

## 日本語

### タイトル
Tadorun - ブックマーク・履歴・タブ検索

### 短い説明
ブックマーク、閲覧履歴、最近閉じたタブを 1 つの高速ポップアップから検索できます。

### 詳細説明
Tadorun は、以前見たページを現在のタブを離れずに探すための Chrome 拡張です。

1 つのポップアップから、ブックマーク、Chrome の閲覧履歴、最近閉じたタブをまとめて検索できます。`site:` `title:` `url:` の検索演算子で絞り込みでき、よく使う検索を保存し、キーボードだけで結果をたどることもできます。

主な機能:
- ブックマーク、履歴、最近閉じたタブの横断検索
- `site:` `title:` `url:` の検索演算子
- 保存済み検索と最近の検索
- ドメイン / フォルダ絞り込み
- URL コピー、新規タブで開く、ブックマークの編集 / 削除
- 多言語 UI

権限について:
- `bookmarks`: ブックマークの検索と編集
- `history`: 閲覧履歴の検索
- `sessions`: 最近閉じたタブの表示
- `tabs`: すでに開いているページの判定
- `storage`: 設定と検索条件の保存

### キーワード案
ブックマーク検索, 履歴検索, 最近閉じたタブ, Chrome 拡張, 作業効率化
